Mode Akses & Sertifikat SSL

Tentukan bagaimana pengguna akan mengakses portal sekolah ini.

🌐 saas-public
Penyedia SaaS (Cloud VPS). Server disewa di cloud dengan IP Publik langsung. Multi-Tenant melayani banyak sekolah.
🏠 saas-local
Penyedia SaaS (Home-Lab). Server di rumah/kantor sendiri (Broadband non-IP publik). Multi-Tenant online via EasyTunnel.
🏫 onpremise
Milik Sekolah (Single-Tenant). Server dedicated di gedung 1 sekolah. Akses cepat LAN Port 80 + Online via EasyTunnel.

Aktivasi & Registrasi Lisensi Server

Seluruh server (SaaS maupun On-Premise) wajib terdaftar di Server Lisensi Pusat guna keperluan administrasi, telemetri, dan otentikasi node.

🛡️ Otentikasi Node Server ke Server Lisensi Pusat saas-public

Server ini akan didaftarkan ke Server Lisensi Pusat (api.absenta.id). Kunci lisensi server diperlukan agar sistem dapat mengirimkan telemetri performa (heartbeat), memverifikasi keabsahan instance, serta mengelola sinkronisasi jaringan dan langganan tenant.

🔑 Sudah Punya Serial Key
Masukkan Serial Key lisensi server resmi yang sudah Anda miliki untuk diverifikasi ke pusat.
✨ Registrasi Server Baru (Gratis)
Daftarkan node server baru dan dapatkan Serial Key resmi otomatis via WhatsApp.
🔄 Klaim / Migrasi Lisensi
Pindahkan lisensi dari server sebelumnya atau konversi node via verifikasi OTP WhatsApp.
