Mode Akses & Sertifikat SSL

Tentukan bagaimana pengguna akan mengakses portal sekolah ini.

🌐 SaaS / Cloud Direct
VPS Cloud dengan IP Publik. Domain sekolah langsung diarahkan ke server ini tanpa VPN tunnel.
🔗 Hybrid (Easy-Tunnel)
Server fisik di sekolah (IP lokal). Terhubung ke internet via WireGuard ke Server Lisensi.
🏫 On-Premise Intranet
Hanya diakses melalui IP lokal / intranet sekolah tanpa akses internet publik.
