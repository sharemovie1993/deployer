Aplikasi Absenta untuk sekolah ini sudah berhasil dipasang pada komputer server sekolah Anda. Namun, saat ini aplikasi baru bisa diakses secara lokal di dalam jaringan intranet lingkungan sekolah.

🔧 Bagi Teknisi IT / Pengelola Server
Pastikan aplikasi Easy Tunnel Gateway Manager di server sekolah sudah dijalankan dan statusnya terhubung (Connected) menggunakan Kunci Lisensi resmi sekolah Anda.
